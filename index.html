      How to use Mind Map
      Mouse actions
      ClickSelect a node or connection
      Double-click canvasAdd a new node
      Double-click nodeCenter / zoom to the node
      Right-clickOpen context menu (node, edge, canvas)
      Drag nodeMove a node
      Ctrl + drag nodeDrop onto another node to connect them
      Mouse wheelZoom in / out
      Drag canvasPan the view
      Keyboard shortcuts
      Ctrl + NNew map
      Ctrl + OOpen JSON file
      Ctrl + SSave JSON file
      NAdd node
      EEdit selected node
      DelDelete selected node / connection
      CToggle connect mode
      EscCancel connect / re-connect / drag-connect / close menus
      FFit map to view
      + / −Zoom in / out
      LAutomatic layout
      TEdit map title
      /Focus search
      F1 / ?Show this help
      Tips
      • Use Connect mode (press C) then click two nodes to link them, or Ctrl + drag from one node straight onto another.
      • Right-click a connection to delete it or re-connect either end to a different node.
      • Right-click a node, a connection, or empty canvas to reach every action with the mouse alone.
      • Attachments are stored as paths only — the JSON never contains file bytes.
