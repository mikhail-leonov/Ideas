      How to use Mind Map
      Mouse actions
      ClickSelect a node or connection
      Double-click canvasAdd a new node
      Double-click nodeEdit the node
      Right-clickOpen context menu
      Drag nodeMove a node
      Mouse wheelZoom in / out
      Drag canvasPan the view
      Keyboard shortcuts
      Ctrl + NNew map
      Ctrl + OOpen JSON file
      Ctrl + SSave JSON file
      NAdd node
      EEdit selected node
      DelDelete selected node / connection
      CToggle connect mode
      EscCancel connect mode / close menus
      FFit map to view
      + / −Zoom in / out
      LAutomatic layout
      TEdit map title
      /Focus search
      F1 / ?Show this help
      Tips
      • Use Connect mode (press C) then click two nodes to link them.
      • Drag nodes freely — positions are saved with the JSON file.
      • Right-click a node or connection for quick actions.
      • Attachments (images, audio, video, files) are managed from the sidebar.
